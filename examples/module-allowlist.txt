# Example module allowlist for `tools/dev mod-load LABEL --allow FILE` and `tools/dev mod-unload`.
#
# Format, one entry per line (blank lines and # comments are ignored):
#
#   release REL
#       Exactly one. REL must equal `uname -r` of the running kernel and name the
#       lib/modules/REL tree that `tools/dev mod-fetch REL --sha SHA256` unpacked.
#
#   LABEL kernel/<dir>/<name>.ko sha256:<64 hex> [param=value ...] [loaded:MODULE ...] [bound:DEVICE ...]
#       LABEL            the name you pass to mod-load / mod-unload (lowercase, digits, _ + . -)
#       kernel/....ko    path of the module below lib/modules/REL
#       sha256:HEX       REQUIRED pin of the .ko; the device re-checks it right before the insmod
#       param=value      module parameters, passed on the insmod line and nothing else (loadable
#                        modules do not see kernel command-line parameters)
#       loaded:MODULE    precondition: MODULE is in /proc/modules (a dependency loaded first)
#       bound:DEVICE     precondition: /sys/bus/platform/devices/DEVICE/driver exists
#
#   Dependencies are listed as their own labels and loaded one by one, in order: there is no
#   modprobe on the device, so nothing is ever autoloaded. Several labels may name the same .ko
#   with different parameters (see msm / msm-zappre).
#   Modules whose name matches the MOD_DENY list in tools/dev (PMIC SDAM, secure QFPROM, charger,
#   fuel gauge, reboot-mode, spidev, syncboss, ...) are refused here whatever the file says.
#
# This file is the GPU-path module set of the mainline kernel (Adreno 650 / msm DRM), in load
# order. The release and every sha256 below are PLACEHOLDERS: copy this file, set `release`, and
# replace each hash with `sha256sum lib/modules/REL/kernel/.../X.ko` of your own build.
#   tools/dev mod-fetch 6.18.0-example --sha <sha256 of modules-6.18.0-example.tar.gz>
#   tools/dev mod-load gpucc --allow examples/module-allowlist.txt
#   tools/dev mod-load msm   --allow examples/module-allowlist.txt
#   tools/dev mod-unload msm --allow examples/module-allowlist.txt
